# CLAUDE.md

Этот файл — руководство для Claude Code при работе с репозиторием.

## Что это за проект

Это **не приложение, а книга**. Маленькая городская книга «Кофе в Городе» — об истории кофейной культуры Гродно. Весь черновик живёт в одном файле [index.html](index.html): HTML здесь используется как формат рукописи и макета одновременно. Публикуется через GitHub Pages ([.github/workflows/static.yml](.github/workflows/static.yml)) — деплой статики из корня при пуше в `master`.

Главный навык для работы с этим репо — **редакторский, а не программистский**. Правки кода почти всегда означают правки текста книги.

## Концепция книги

- **Где читают:** книга лежит в кофейне, её листают, пока ждут заказ. Должна читаться целиком за время приготовления капучино.
- **Объём:** ~20 страниц. Компактность — принцип, а не ограничение.
- **Тон:** лёгкий журналистский, простой язык, «вайб старой книги». Нейтральное изложение фактов, без авторского «я».
- **Главный вопрос книги:** «Откуда появился кофе у нас в Городе (Гродно)?»
- **Хронология:** от первых упоминаний кофе на гродненских землях (Тизенгауз, шляхта, Мицкевич) до современности, с короткой главой про кофейный кризис и климат.
- **Фокус на картинки:** иллюстраций много, текст их обрамляет, а не наоборот.
- **Интерактивность — фишка книги:** маршрут по местам старых кофеен (гл. 7), карточки современных кофеен (гл. 8), «кофейный паспорт» со штампами и исторический чеклист (стр. 19).

## Структура index.html

Один файл. Каждая страница книги — **отдельный** блок `<div class="page">` с комментарием-разделителем `<!-- ===== СТР. N ===== -->`; глава может занимать несколько таких блоков. Порядок глав:

0. Передняя обложка (стр. 0, пока пустая)
1. Вступление «Пока вам несут кофе» (стр. 1)
2. Мировая история кофе за две минуты — таймлайн (стр. 2–3)
3. Кофе по-шляхетски: кавярка, Мицкевич (стр. 4–5)
4. Тизенгауз и первый кофегауз (стр. 6–7)
5. Межвоенные кофейни: Котовский, «Ориент», «Стамбул», Шиповский (стр. 8–9)
6. «Тишина» — война и Холокост (стр. 10)
7. Кофе по-советски (стр. 11)
8. Маршрут по старому городу (стр. 12–13)
9. Современные кофейни — 8 карточек (стр. 14–17)
10. Кофейный кризис и климат (стр. 18)
11. Кофейный паспорт: штампы + чеклист (стр. 19)
12. Колофон: источники, контакты, QR (стр. 20)
13. Задняя обложка (стр. 21, пока пустая)

**Обложки — `<section class="page cover">`, а не div.** Это намеренно: раскладка разворотов определяет левые/правые страницы через `nth-of-type` по div'ам, и section-обложки не сбивают чётность внутренних страниц. Передняя (`.cover-front`) стоит одна справа, задняя (`.cover-back`) — одна слева, как закрытая книга.

## Служебная разметка (важно!)

В черновике есть блоки трёх типов — их назначение строго различается:

- **`.figure` (пунктирная рамка)** — плейсхолдер иллюстрации: описание сцены, размер/пропорции и готовый промпт для нейросети в блоке `.prompt`. Промпты пишутся **на английском**, всегда заканчиваются `no text, no letters, no frame, no watermark` и указанием пропорций. Принцип: «текст отдельно, картинка отдельно» — подписи, даты и номера кладутся вёрсткой, нейросеть текст не рисует.
- **`<span class="todo">✎ …</span>` (жёлтые пометки)** — факты и формулировки, требующие проверки перед печатью. Не удалять без проверки факта; новые сомнительные утверждения помечать так же.
- **`.ednote` («ДЛЯ РЕДАКЦИИ»)** — служебные заметки, в печатную книгу не идут. В разметке стоят на своём месте в тексте, но CSS выносит их на правое поле страницы (как маргиналии), чтобы полоса набора содержала только реальный текст книги; на экранах уже 1250px показываются внутри страницы.

Прочие переиспользуемые компоненты: `.insight` (врезка «Кстати»), `.quote`, `.timeline`, `.cards`/`.card` (модификатор `.cards-stack` — карточки в одну колонку, для страниц современных кофеен), `.route`, `.stamps`/`.stamp`, `.checklist`, `.bignums`, `.pagenum`.

## Редакционные правила

- **Факты, не мнения.** В карточках современных кофеен — только проверяемые фишки и плюсы, никаких рейтингов, купленных отзывов и оценочных сравнений. Шаблон карточки: год открытия, адрес, фишка (одно предложение), один факт, что взять в первый раз, реальное фото (не генерация).
- **Военная глава («Тишина», стр. 10)** — только сухие факты, без художественных подробностей. Полупустая страница — сознательный приём, не «недописанность».
- **Стиль текста:** короткие абзацы, разговорные мостики между главами, без академизма. Образец интонации — уже написанные главы.
- **Стилистика иллюстраций по эпохам:** до XX века — гравюра/офорт (сепия, штриховка); 1930-е — винтажное ч/б фото с зерном; советское время — гуашь/ретро-плакат. Для исторических зданий и портретов план А — реальные архивные материалы, генерация — запасной вариант с честной подписью «реконструкция-фантазия».
- **Карта маршрута не генерируется нейросетью** — только стилизация реальной схемы улиц (OpenStreetMap) дизайнером; генерируется лишь декор (картуш, роза ветров).
- **Язык книги — русский**, с локальными словами (кавярня, кофегауз, буза). Цитата Мицкевича — вопрос языка подачи ещё открыт (см. todo на стр. 4–5).
- **Нумерация страниц:** при добавлении/удалении контента следить за `.pagenum`, перекрёстными ссылками в тексте («страницы 12–13», «страница 18») и тем, чтобы общий объём держался около 20 страниц.

## Формат A4 и печать

- Каждый `<div class="page">` — ровно одна страница книги и ровно один лист A4 (`width:210mm; min-height:297mm`, flex прижимает `.pagenum` к низу листа). Div-«разворотов» на несколько страниц не бывает: если контент не помещается в лист — он делится на отдельные страницы-divы. После правок проверять, что ни одна страница не выросла выше 297mm.
- На широких экранах (≥1680px) страницы показываются парами, как открытая книга: CSS-grid на `body`, нечётные страницы справа, чётные слева, стр. 1 — одна справа (как в настоящей книге); у «корешка» — внутренняя тень. Шапка черновика — тег `<header>`, а не div: `nth-of-type` должен считать только страницы.
- Заметки `.ednote` на полях зеркалятся: у левых (чётных) страниц — левое поле, у правых — правое (на экранах ≥2120px; на 1680–2119px места для полей нет — заметки показываются в потоке).
- Печать настроена через `@page{size:A4;margin:0}` и `@media print`: каждый `.page` начинается с нового листа (`break-after:page`), `.draft-banner` и `.ednote` не печатаются, плейсхолдеры `.figure`/`.prompt` сжимаются (в книге их место займут картинки).
- `min-height` в печати — 296.5mm (не 297mm): запас на округление, иначе Chrome добавляет пустые листы.
- **После правок контента проверять печать:** отрендерить PDF headless-хромом (`--headless --print-to-pdf`) и убедиться, что нет листов-«хвостов», где остался один номер страницы. Если одностраничный div переполнился на несколько мм — сокращать вёрстку/отступы, а не текст.

## Чего не делать

- Не превращать книгу в энциклопедию кофе — фокус строго на Гродно; мировая история уже ужата в один таймлайн и расширению не подлежит.
- Не добавлять JS, фреймворки, сборку — это статичная рукопись, простота файла осознанна.
- Не вписывать «красивые» исторические факты без пометки `✎` — всё непроверенное должно быть видно редактору.
- Не трогать draft-banner наверху файла без запроса — это инструкция для людей, читающих черновик.
